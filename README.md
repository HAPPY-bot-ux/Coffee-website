🧐 Project Overview
This project aims to create a simple yet engaging website to educate users on the different aspects of coffee. The website's design includes interactive elements such as buttons, dynamic content, and animations to make the learning experience enjoyable. Whether you're looking to explore coffee types, brewing methods, or even the history of your favorite cup, the Coffee Website will provide you with all that and more.

The front-end of the site is built using:

HTML for the structure of the website.
CSS for styling the content, layout, and animations.
JavaScript to handle interactivity and dynamic features.
💻 Technologies Used
HTML:

For building the structure of the website, such as the content of the pages, headers, footers, and sections.
CSS:

For styling the website, including colors, typography, layout, and responsiveness for mobile devices.
Provides the visual appeal and aesthetic, from the overall layout to the fine details like buttons and hover effects.
JavaScript:

For dynamic and interactive features such as buttons, forms, and fetching data for various sections.
Enhances user experience with interactions like navigation buttons, pop-up modals, and interactive menus.
✨ Features
🌟 Home Page:

Introduction to the world of coffee with visually appealing images and brief descriptions of different coffee types.
☕ Interactive Coffee Menu:

A section showcasing different coffee beverages (like Espresso, Cappuccino, etc.) with detailed descriptions and images.
💡 Coffee Brewing Methods:

Information on various brewing techniques (e.g., French Press, Espresso, Pour-Over, Aeropress).
🖱️ JavaScript Interactivity:

Buttons to navigate through sections, and pop-up modals with additional information about specific coffee facts or brewing tips.
📱 Responsive Design:

The website adapts seamlessly to different screen sizes, ensuring it's mobile-friendly and easy to navigate on smartphones, tablets, and desktops.
